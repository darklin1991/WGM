4狼 4神 4民，共 12 人。

## 夜晚順序

```
守衛 → 狼人 → 女巫 → 預言家（查完當場給金水／查殺）→（獵人手勢）
```

狼王與一般狼**合併成同一個「狼人」步驟**（互相相認、一起決定刀口），登記完 4 位座次後再單獨指認哪一位是狼王。

獵人不在 `nightOrder` 裡（沒有主動夜間行動），流程產生器自動把牠補在最後 —— 這是刻意的：法官必須先收完女巫的毒藥，才知道該給獵人哪個開槍手勢。

## 狼王的槍

與獵人**判定方式不同** —— 看的是「**有沒有被自刀**」，不是死因：

| 情況 | 可否開槍 |
|---|---|
| 被自刀出局 | ✅ |
| 被自刀＋同時吃毒 | ✅（死因記為毒，但槍還在） |
| 沒被自刀、只吃毒 | ❌ |
| 被自刀但被守衛守住（沒死） | ❌ |
| 同守同救而死 | ✅（也是自刀造成的） |

**狼王不給夜間手勢** —— 狼隊自己知道有沒有自刀，白天起來直接發動技能。這點與獵人不同（獵人每晚都要叫起來看手勢，因為牠不知道自己有沒有被毒）。

## 獵人

| 死因 | 可否開槍 |
|---|---|
| 被狼刀死 | ✅ |
| 同守同救而死 | ✅ |
| 被放逐 | ✅ |
| 被毒死 | ❌（`poisonedHunterCannotShoot`） |

每晚都要叫起來給手勢 —— 獵人自己不知道有沒有被毒，只有法官知道。
