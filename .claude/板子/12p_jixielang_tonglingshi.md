# 12人 機械狼通靈師

`assets/presets/12p_jixielang_tonglingshi.json`

六個板子裡最複雜的一個。機械狼的資訊時序與學習機制有一堆非做不可的理由，改動前先看懂下面的說明。

## 配置

| 陣營 | 角色 |
|---|---|
| 狼 | 狼人 ×3、**機械狼** ×1 |
| 神 | **通靈師**、女巫、獵人、守衛 |
| 民 | 平民 ×4 |

4狼 4神 4民，共 12 人。

## 夜晚順序

```
機械狼 → 守衛 → 狼人 → 女巫 → 獵人 → 通靈師（查完當場給真實身分）→（機械狼結尾）
```

這個順序有兩條**不能隨手改**的理由：

- **通靈師排最後**：牠查的是**真實身分**，法官必須先登記完所有人才答得出來。
- **獵人夾在女巫與通靈師之間**：排在女巫之後是因為要先收完毒才知道給哪個開槍手勢；排在通靈師之前是為了讓通靈師殿後。

## 機械狼

**一晚睜眼兩次**：

| 輪次 | 內容 |
|---|---|
| **開頭那一輪**（每晚都有） | 開刀手勢 → 有刀就選第一刀 → 是否使用技能 |
| **結尾那一輪** | 告知學到的身分與開槍手勢 |

為什麼非得兩次：機械狼**不與小狼相認**，所以「今晚有沒有刀」和「學到了什麼」只有法官知道，必須用手勢告訴牠。而牠第一個睜眼時身分都還沒登記完、女巫的毒也還沒收，那時法官根本講不出來 —— 只能拆成兩次。

**開頭那一輪每晚都有**，就算沒技能可用（學到平民、或學了還沒生效）也要叫起來，否則機械狼無從得知自己有沒有刀。

### 基本規則

- 不能自爆
- 開局**不帶刀**，其餘小狼全數出局後才獨自帶刀
- 可於任一晚學習一名玩家的身分技能，**整局限一次**，**隔夜起生效**
- 學習對象**不能選自己**

### 學得到的六種身分

這個板子上除了機械狼自己，場上就這六種：

| 學到 | 之後每晚做什麼 |
|---|---|
| **守衛** | 守一人 —— 擋刀，或把毒**反彈**給下毒者。守護紀錄與原守衛各自獨立 |
| **女巫** | **只有一瓶毒藥，沒有解藥**。藥量與原女巫各自獨立 |
| **通靈師** | 查一人的真實身分 |
| **獵人** | 沒有夜間動作；**只有吃刀或吃推才能開槍**（比獵人本人嚴格，吃毒、殉情都不行）。槍**學到就有**，不等隔夜生效 |
| **平民** | 什麼都沒有，整晚不睜眼（結尾那輪也不出現） |
| **狼人** | 帶刀那晚多砍一刀；雙刀集中同一人**破盾** |

### 帶刀與雙刀

小狼還活著時機械狼**沒有刀**，學到狼人也砍不了。小狼全滅後：

- 第一刀在**開頭那一輪**砍
- 第二刀在**狼人那一格**砍（學到狼人才有）
- 兩刀分開在兩個畫面收，剛好讓同一人可以被選兩次

**破盾**：兩刀集中同一人 → 守衛的守護**與**女巫的解藥**都失效**，必死。死因記為狼刀，不構成同守同救。

## 通靈師

每晚查驗一名玩家的**真實身分**（不只好人／狼人），無次數限制，站預言家的位置。
查驗結果**當場**比給他看，不是等到夜晚結算頁 —— 那時他早就閉眼了。

### 查到機械狼時，看到的是牠學到的身分

擔當 2026-09-19 指定。這是機械狼的核心強度，**不是 bug**：

| 機械狼的狀態 | 通靈師看到 | 預言家看到 |
|---|---|---|
| 還沒學習 | 機械狼 | 查殺 |
| 學到守衛／女巫等好人身分 | **那個身分** | **金水** |
| 學到狼人 | 狼人 | 查殺 |

兩條容易搞錯的地方：

- **偽裝當晚就生效**，技能仍是隔夜生效 —— 兩者**刻意不同步**，不要順手改成一致。
  機械狼第一個睜眼、通靈師最後睜眼，所以同一夜就查得到。
- **偽裝只罩機械狼自己**。被學習的那位（例如真守衛）照實顯示，不受影響。

判定寫在 `NightArbitrator.apparentRoleAt`，夜晚流程頁與結算頁共用同一份 ——
分兩處算遲早會給出不一致的答案。

## 規則旗標

共通旗標之外，這個板子沒有額外指定。以下兩個與機械狼相關的旗標吃預設值（都是 `true`）：

```
mechanicGuardReflectsPoison      true   學到守衛的守護把毒反彈給下毒者
mechanicDoubleKnifeBreaksShield  true   雙刀集中同一人破盾
```
