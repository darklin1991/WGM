# 12人 狼美騎士

`assets/presets/12p_langmei_qishi.json`

## 配置

| 陣營 | 角色 |
|---|---|
| 狼 | 狼人 ×3、**狼美人** ×1 |
| 神 | 預言家、女巫、守衛、**騎士** |
| 民 | 平民 ×4 |

4狼 4神 4民，共 12 人。

**這個板子沒有獵人** —— 神職是預女守騎，所以整局不會出現獵人的開槍手勢那一步。

## 夜晚順序

```
守衛 → 狼人 → 狼美人 → 女巫 → 預言家（查完當場給金水／查殺）
```

狼美人與一般狼**合併成同一個「狼人」步驟**（互相相認、一起決定刀口），登記完 4 位座次後再單獨指認哪一位是狼美人；接著狼美人**單獨睜眼魅惑**。

騎士不在 `nightOrder` 裡（沒有主動夜間行動），**夜裡完全不會被叫起來** —— 身分在開局前的登記頁就確認了（擔當 2026-09-19 指定，見修改歷程）。

## 狼美人

### 魅惑

- **不能自刀**：狼隊的刀不可指向狼美人自己
- **不可連續兩晚魅惑同一人**（與守衛的「不可連守」對稱）
- **沒選就是沒魅惑**：本晚不指定的話，前一晚的對象**一併解除**，不沿用

### 殉情

狼美人出局時，**當晚被魅惑的那位**隨之死亡。

| 情況 | 是否殉情 |
|---|---|
| 夜裡出局（刀／毒／奶穿） | ✅ |
| 被放逐 | ✅ |
| **被騎士決鬥致死** | ❌ —— 騎士唯一能救下殉情者的時機 |
| 被魅惑者已因他故死亡 | 死因維持原本的，不改記殉情 |
| 被魅惑者被守衛守住 | 仍然死亡（守衛防不了殉情） |
| 殉情死的獵人 | 可開槍（死因不是毒）—— 本板無獵人，但規則如此 |

實際例子：狼美人第 1 夜魅惑 10 號、第 2 夜改魅惑 12 號、第 3 夜魅惑 9 號後被毒死 → **殉情的是 9 號**，10 號與 12 號早就解除了。

## 騎士

無夜間行動，夜裡不會被叫起來。決鬥的入口在白天的發言計時頁。

**決鬥時機**：警長競選結束之後、放逐投票開始之前（白天的發言階段）。上警階段不可決鬥，投票開始後也不可。

入口是**白天發言計時頁上的一顆按鈕**，一離開那一頁（進投票）視窗就關了。

| 項目 | 規則 |
|---|---|
| 對手是狼人 | 對手死亡，**立即進入黑夜**，跳過當天投票 |
| 對手是好人 | 騎士自己出局，白天照常繼續走到投票 |
| 決鬥次數 | **整局只有一次**，決鬥到狼活下來也不能再發動 |
| 對手是槍牌 | **不能開槍** —— 決鬥是騎士的裁決，對手沒有反擊機會 |
| 對手是狼美人 | 被魅惑者**不殉情** |

決鬥出狼走的是和自爆相同的「立即進夜」路徑，但**警徽流照樣要走** —— 被決鬥掉的可能就是警長。

## 規則旗標

共通旗標之外，這個板子多指定四個：

```
charmCannotRepeatTarget       true   不可連續兩晚魅惑同一人
wolfBeautyCannotSelfKill      true   狼隊不可把刀指向狼美人
knightDuelBlocksCharmSuicide  true   被騎士決鬥致死時殉情不發動
knightDuelEndsDay             true   決鬥到狼立即進入黑夜
```
